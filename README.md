# Tai-Sheng Yeh

食品科學、食品分析與互動式教學教材作品集。  
Portfolio for food science, food analysis, and interactive teaching materials.

## Featured Teaching Materials

### Food Analysis / 食品分析

- [Hyperspectral Food Analysis](https://github.com/Tai-ShengYeh/hyperspectral-food-analysis)  
  高光譜食品分析教材：Python、Orange Data Mining、SpectroFood、互動中英投影片與可重現工作流。

- [Hyperspectral Food Analysis Demo](https://github.com/Tai-ShengYeh/hyperspectral-food-analysis-demo)  
  SpectroFood 公開資料集的 Python / Orange Data Mining 教學 demo。

- [Raman Food Analysis](https://github.com/Tai-ShengYeh/raman-food-analysis)  
  Raman spectroscopy in food analysis：互動式投影片與形成性評量小遊戲。

- [Microplastic Food Analysis](https://github.com/Tai-ShengYeh/microplastic-food-analysis)  
  食品中微塑膠檢測 3 小時互動教材，涵蓋 NIR、FTIR、Raman、Py-GC-MS、LC-MS。

- [Microplastic Teaching](https://github.com/Tai-ShengYeh/microplastic-teaching)  
  高中彈性課程：微塑膠 × 食品安全，22 頁 / 60 分鐘教學投影片。

### Food Nutrition Chinese Teaching / 食品營養華語教學

- [Food Nutrition Chinese Teaching](https://github.com/Tai-ShengYeh/food-nutrition-chinese-teaching)  
  A2–B1 食品營養華語文獻閱讀互動教學工具與脫敏班級報告。

- [Cocoa-Free Chocolate Lesson](https://github.com/Tai-ShengYeh/cocoa-free-chocolate-lesson)  
  無可可巧克力主題互動簡報、小遊戲與課堂投票。

- [GLP-1 Chinese Class](https://github.com/Tai-ShengYeh/glp1-chinese-class)  
  GLP-1 食品營養華語課堂互動小遊戲。

### AI / Software Projects

- [Yeh AI Customer Service](https://github.com/Tai-ShengYeh/yeh-ai-customer-service)  
  LINE + Supabase + React + OpenAI / Gemini 的 AI 客服系統 prototype。
