## Featured Teaching Materials

### 光譜 × 食品分析（化學計量學）· Spectroscopy × Chemometrics
四種以上光譜技術配 **PCA / PLS / PLS-DA**，三層教學：看影片建直覺 → 讀 Python 學算法 → 用 Orange 親手做。

- **NIR 近紅外光譜** — [chemometrics-teaching](https://github.com/Tai-ShengYeh/chemometrics-teaching) · Tecator 肉品資料，PLS 預測脂肪含量。
- **MS 質譜** — [ms-food-analysis](https://github.com/Tai-ShengYeh/ms-food-analysis) · 白酒 GC-MS 代謝體，PLS-DA 分辨葡萄品種。
- **Raman 拉曼光譜** — [raman-food-analysis](https://github.com/Tai-ShengYeh/raman-food-analysis) · 互動投影片＋形成性評量小遊戲。
- **Hyperspectral 高光譜影像** — [hyperspectral-food-analysis](https://github.com/Tai-ShengYeh/hyperspectral-food-analysis) · SpectroFood，Python + Orange 可重現工作流（另有 [demo](https://github.com/Tai-ShengYeh/hyperspectral-food-analysis-demo)）。
- **NMR 核磁共振光譜** — [nmr-food-analysis](https://github.com/Tai-ShengYeh/nmr-food-analysis) · 40 支葡萄酒 ¹H-NMR，PLS 定量蘋果酸。
- **Fluorescence 螢光光譜 EEM** — [olive-oil-eem](https://github.com/Tai-ShengYeh/olive-oil-eem) · 橄欖油加速老化，PCA 軌跡＋鑑別新鮮度。
- **FTIR 紅外光譜** — [ftir-food-analysis](https://github.com/Tai-ShengYeh/ftir-food-analysis) · 即溶咖啡 Arabica vs Robusta（搭配 [coffee PGMM R 報告](https://github.com/Tai-ShengYeh/coffee_pgmm_R_code)）。
- **Benchtop NMR 桌上型 NMR** — [benchtop-nmr-coffee](https://github.com/Tai-ShengYeh/benchtop-nmr-coffee) · 60 支咖啡 16-OMC 摻假標記。
- **GC 氣相層析** — [coffee-gc-analysis](https://github.com/Tai-ShengYeh/coffee-gc-analysis) · 14 支咖啡層析指紋，留一驗證 92.9%。
- **XRF X 射線螢光** — [xrf-food-analysis](https://github.com/Tai-ShengYeh/xrf-food-analysis) · 元素指紋；以開放蜂蜜元素表（CC0）即時實算真假與摻假鑑別。
- **LIBS 雷射誘導擊穿光譜** — [libs-food-analysis](https://github.com/Tai-ShengYeh/libs-food-analysis) · 原子發射光譜；咖啡品種過擬合教訓、蜂蜜摻假定量。
